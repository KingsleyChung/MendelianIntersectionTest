高三生物公开课互动教具 —— 学生亲手走完孟德尔测交实验的完整九步流程，从去雄套袋一路做到子代性状分离比的统计结论。

## 教学流程

```
去雄 → 套袋 → 取粉 → 授粉 → 再套袋 → 收种子 → 播种 → 生长观察 → 分类统计
```

- **去雄**：用解剖刀横向切掉母本的雄蕊，保留雌蕊
- **套袋**：3 朵花各套一个纸袋，隔离外来花粉
- **取粉 / 授粉**：从父本花药取粉，涂到母本柱头上
- **再套袋**：重新隔离，等待结种子
- **收种子**：3 个豆荚依次采摘，共取出 48 粒种子
- **播种**：48 粒种子播进 16 穴，每穴 3 粒
- **生长观察**：48 株子代长成
- **分类统计**：把高茎与矮茎"拔出来"左右分堆，数出数量与比例

## 教材对齐

人教版高中生物 **必修2《遗传与进化》第 1 章第 1 节** —— 孟德尔豌豆杂交实验（一）

设计上严守两条内容红线：

1. **高茎与矮茎一律使用同一种绿色**，区别只有株高本身。田间观察环节不得用颜色替学生把结论念出来。
2. **去雄后雌蕊必须保留**。只剩一个空洞虚线圈会让学生误以为整朵花被掏空，也无法理解"为什么还要授粉"。

## 技术要点

- **2.5D 等距投影**：CSS `rotateX` + `rotateZ` 绘制豌豆田，立牌精灵始终正对镜头
- **逐朵状态位**：`flowers[i] = {emas, bag, fert}`，让"3 朵花套 3 次"成为状态机的自然结果而非特判
- **FLIP 跨坐标系动画**：用真实 `getBoundingClientRect()` 起止位置驱动"拔苗→飞行→落格"，自动吸收投影与缩放
- **遗传学数学约束**：`48 = lcm(2,3) × 8`，使 1:1（24∶24）与 2:1（32∶16）能同时精确成立，且 48 恰好等于 3 个豆荚 × 16 粒、16 穴 × 3 粒
