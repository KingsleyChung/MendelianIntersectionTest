# 果蝇实验室 · 基因在染色体上

[在线体验](https://kingsleychung.github.io/MendelianIntersectionTest/fruit-fly/)

面向高中生物公开课的两轮果蝇杂交互动模拟。平板优先，支持触屏点选后拖动或点目标位置，电脑可直接拖动或全程点击；手机采用单列布局与横向材料架。

## 教学流程

第一轮：F₁红眼雌性 × 白眼雄性，四类后代理论比例为1∶1∶1∶1。眼色基因仅位于X上和位于XY同源区段的两种假说，都符合本轮结果。

第二轮：第一轮获得的白眼雌性 × 实验室另行提供的纯合野生型红眼雄性。雌性全红眼、雄性全白眼的观察，支持仅位于X上的假说。假说三下野生型雄性必须为XᵂYᵂ，不能用F₁雄性XᵂYʷ替代。

操作包括材料选择、培养快进、转移亲本、放大辨认与分类、批量统计、两种假说的遗传过程播放和实验记录回看。

## 使用与验证

`index.html` 是自包含单文件，所有样式、脚本和SVG内联，没有外部依赖。可直接用浏览器打开，或由GitHub Pages发布。

网页计数明确标为固定教学模拟数据，不是历史实验原始数据。F₂红眼雌性标为混合基因型群体。果蝇和培养过程均为教学示意。

已验证遗传模型、1024×768平板尺寸完整两轮流程和鼠标分类拖拽、768×1024竖屏布局、320像素手机完整两轮流程及390像素手机布局。真实iPad Safari和Android平板触摸仍需教师实机验收，教材版本与假说编号需对照课堂讲稿确认。

完整源码、遗传测试、工作日志和交接文档见[开发目录](source/README.md)及[交接入口](source/docs/HANDOFF.md)。后续每次修改并检查后，都提交并推送到main。
