# 接手规则

先读 `docs/HANDOFF.md`，再读 `docs/WORK_LOG.md` 和 `docs/VALIDATION.md`；`README.md` 面向使用者。不要依赖旧聊天记录判断当前状态。

## 用户已确认的要求

- 人教版高中生物《基因在染色体上》，面向公开课小组实验，约5分钟。
- 平板触屏优先，电脑键鼠兼容，手机至少能完成流程。保留拖拽和点选两条操作路径。
- 生动的培养瓶、果蝇转移、观察与分类操作，避免把流程改成文字选择题。
- **每次修改并检查后，都要提交并push到指定仓库的main分支。** 此授权延续到后续修改，不必重复询问。若推送失败，保留提交并明确记录阻塞原因，不能宣称发布成功。
- 每轮工作都更新工作区日志、验证记录及交接状态，并随本轮改动同步推送。

## 修改与发布边界

- 开发源文件在本工作区；`dist/果蝇实验室.html`由`python3 build.py`生成，不直接改生成文件。
- 指定仓库：`https://github.com/KingsleyChung/MendelianIntersectionTest.git`。本机检出路径及操作步骤见交接文档。
- 仓库根`index.html`是已有豌豆实验，保留。果蝇发布页是`fruit-fly/index.html`。
- 仓库`fruit-fly/source/`保存开发源码和交接文档的镜像，供其他Codex或另一台电脑恢复。不要把镜像当成另一套独立源文件同时修改。
- fetch后检查分支差异，只对本轮相关文件提交；不要覆盖别人的未提交改动，不force push。
- 遗传计算改变时运行遗传模型测试；交互/布局改变时检查对应浏览器流程。浏览器尺寸测试不等于真实平板触摸验收。
- 保留模拟数据标识、两种假说的不同基因型、F₂雌性混合群体和第二轮额外提供材料的来源。未经验证，不把教材版本、历史数量、实机或线上发布当作已确认事实。
- 不写入或推送凭证、Git私有配置、缓存及`.DS_Store`。
