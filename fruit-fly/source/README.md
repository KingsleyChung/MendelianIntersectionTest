# 果蝇实验室 · 基因在染色体上

面向高中生物公开课的小组互动网页。平板优先，电脑和手机可完成完整流程。无需账户、数据库、第三方资源或联网加载字体。

## 打开方式

- 电脑：双击 `index.html`，选择浏览器打开；也可打开 `dist/果蝇实验室.html`，这是无需附带其他文件的便携版。
- 本机预览：在本目录执行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 http://127.0.0.1:8765 。该地址仅供本机使用，平板无法通过它访问。
- 平板与手机：建议将 `dist/果蝇实验室.html` 放到学校允许访问的静态网站，使用 Safari 或 Chrome 打开网页地址。部分系统的文件预览、微信内置文件预览不会运行 JavaScript，不能用来验收本网页。托管不需要后端。
- 分享：`dist/果蝇实验室-交付.zip` 含便携网页及本说明。

## 操作方法

触屏先点选培养瓶或果蝇，再拖到目标，或直接点目标完成操作。未选中的卡片保持滚动能力；已选中的对象可拖动。鼠标可以直接拖动，也可以全程点击。选择后可替换亲本或清空配置。

第一轮选 F₁红眼雌性 + 亲本白眼雄性，开始培养，可跳过生活史动画。点击备用瓶移走亲本，再按眼色和性别归类四只代表性后代，系统统计整批后代。第一轮所得四类后代在进入第二轮时加入材料架。

第二轮选第一轮白眼雌性 + 实验室另行提供的纯合野生型红眼雄性。完成相同步骤，比较两个假说的预测，形成结论。图解可播放染色体分离、进入生殖细胞及组合成后代的示意；实验记录中可回看各轮图解。

旋转屏幕不会清空进度。刷新页面或重新开始会清空本次进度；本版本不存储个人数据或持久化实验记录。

## 科学内容及默认值

- 原图重绘：纯合红眼雌性 × 白眼雄性 → F₁全红眼 → F₁雌雄交配 → F₂红眼∶白眼理论上为3∶1，白眼均为雄性。
- 假说二：眼色基因仅位于X染色体上，Y上无对应等位基因。假说三：眼色基因位于XY同源区段，X和Y均有对应基因。
- 第一轮两套模型均预测四类后代1∶1∶1∶1；第二轮假说二预测雌性全红眼、雄性全白眼，假说三在指定纯合野生型雄性条件下预测雌雄全红眼。
- F₂红眼雌性是两种基因型的混合群体。第一轮获得的红眼雄性、F₁红眼雄性和F₂红眼雄性，在假说三下均为XᵂYʷ，不能替代第二轮实验室提供的XᵂYᵂ雄性。
- “纯合野生型雄性”沿用需求中的材料概念，仅在假说三下对应XᵂYᵂ；假说二下雄性为XᵂY，不称纯合。网页基因型说明保留此区别。
- 计数为固定教学模拟数据，不是历史实验实测数据：第一轮红眼雌126、红眼雄132、白眼雌120、白眼雄115；第二轮红眼雌307、白眼雄289，其余0。需求图片的精确数量未确认，因此未当作史实转录。
- 生活史动画为示意；移走亲本的步骤说明真实实验需在子代成虫出现前完成。果蝇造型用于辨认示意，不是显微图像。
- 首版只实现上述两轮实验。其他杂交组合给出当前任务的解释和更换路径，不生成推测结果。
